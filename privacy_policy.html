Privacy Policy

This application is a personal automation tool used solely by its developer to publish Pins to their own Pinterest account. It is not distributed to or used by any other end users.

Data collected

This app accesses only the Pinterest account data required to create and manage Pins and boards on the developer's own account (via the Pinterest API OAuth scopes pins:read, pins:write, boards:read, boards:write). No data is collected from, or shared with, any third boards:write). Requests needed to publish or manage Pins are sent to Pinterest. The API is hosted by the developer on Render.

Data storage

OAuth access and refresh tokens are stored on a persistent disk attached to the developer's Render service. Tokens are used only to authenticate requests to Pinterest and are not included in the source repository.

Contact

Questions about this policy can be sent to the developer directly.
